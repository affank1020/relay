# Prepare PR

Review the full base-to-head diff before asking for independent review. Read the requirements and tests, identify defects and missing cases, fix what the authorised tools and permissions allow, and report checks that actually ran.

This Skill is guidance, not an extension or permission grant. Never claim to have run tests, pushed code, received approval or merged without an authoritative tool receipt. Do not bypass Relay's tool allowlists. Repository writes require a separately authorised connector capability. Report unverified checks and outstanding risks plainly.
